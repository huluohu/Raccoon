## 2. 设计 Token（tokens.css，唯一色值来源）

**四套浣熊主题**（Ottr 思路：主题 = 吉祥物换皮）：`night 夜行`（默认，深蓝黑 + 荧光薄荷）、
`scarf 围巾`（暖黑褐 + 围巾金）、`snow 雪绒`（浅冷灰 + 墨青）、`berry 浆果`（深李紫 + 浆果珊瑚）。
每套主题定义完整的一组画布/文字/语义色，并各自携带一组 `--logo-*` 浣熊形象变量
（`--logo-fur/-face/-mask/-scarf/-ear`）——切换主题时品牌徽标与六表情整体换皮，
浣熊的毛色、眼罩、围巾颜色随主题走，这是「主题与形象关联」的落地机制。

语义铁律：

- **强调色**（`--accent`）承担且仅承担：活跃态指示、主行动按钮、实时指示、当前导航。每屏强调色面积克制，不铺大底。
- **金色**（`--gold`）是品牌色不是动作色：只作全站品牌点缀（徽标围巾、收藏类徽章）与 scarf 主题的强调色。
- 语义色（success/warning/danger/info/neutral）按各主题底色调亮度；正文对比 ≥ WCAG AA 4.5:1（闸门按主题断言）。
- 数字一律 `font-variant-numeric:tabular-nums`；等宽场景（眉题/时间戳/ID/日志/路径）用 `--font-mono`（系统等宽栈，不引字体文件）。
- 深色主题封面/缩略图加 1px 描边防「浮空」；主题切换即时生效并记忆（localStorage `raccoon.theme`，旧值 dark→night、light→snow 迁移）。

**页头签名**（全站统一，`PageHeader` 组件）：等宽眉题（`— DOWNLOADS / QUEUE` 式，11.5px、字距 0.14em、大写、`--text-3`）+ 页面大标题（`--font-display` 800，中文句点收尾）+ 副行（实时状态或一句说明）+ 右侧动作区。顶栏不再承载页面标题——标题是页面构图的一部分（控制台方向裁决，覆盖旧版「标题归属顶栏」）。

以 night 为例的 token 骨架（其余主题同构，值见 tokens.css）：

```css
:root{
  /* 画布（night：深蓝黑） */
  --bg:#0A0E17; --surface:#101624; --surface-2:#161E30; --surface-3:#1D2740; --border:#232E4A;
  /* 强调（荧光薄荷）：活跃/主行动/实时 */
  --accent:#35E0A6; --accent-strong:#6BEFC4; --accent-soft:rgb(53 224 166 / 12%);
  /* 品牌金：点缀 + scarf 主题强调 */
  --gold:#F5B93C;
  /* 文字 */
  --text-1:#F2F5FA; --text-2:#A8B3C7; --text-3:#6B7690;
  /* 等宽（眉题/数据/日志） */
  --font-mono: ui-monospace, SFMono-Regular, Menlo, monospace;
  /* 浣熊形象（每主题覆盖） */
  --logo-fur:#3A4A66; --logo-face:#EEF2F8; --logo-mask:#10141D; --logo-scarf:#35E0A6; --logo-ear:#35E0A6;
  /* 圆角三档 + 阴影（深色主题阴影退化为 1px 描边） */
  --radius-ctrl:8px; --radius-card:14px; --radius-modal:20px; --radius-pill:999px;
  --shadow-1/2/3: …
}
[data-theme='scarf']{ /* 暖黑褐 + 围巾金 + 金围巾浣熊 */ }
[data-theme='snow']{ /* 冷灰白 + 墨青 + 银灰浣熊 */ }
[data-theme='berry']{ /* 深李紫 + 浆果珊瑚 + 紫调浣熊 */ }
```

其他规则：中英文混排预留间隙（`text-autospace`）；术语/路径/命令保持原文不翻译；
遮罩层 `--scrim` 按主题配深浅（浅色主题压树影灰、深色主题压纯黑，避免「发灰发白」）。

## 5. 浣熊表情体系（§10.10 ③）

| 状态 | 表情 | 场景 | 文案示例 |
| --- | --- | --- | --- |
| waiting | 眼罩半搭 + 哈欠嘴 | 排队、等待登录 | 「排着呢，前面 3 个，急也没用」 |
| working | 眼罩推上头顶 + 叼金牌箭头 | 下载中、解析中 | 「搬着呢，43% · 12.4 MB/s」 |
| done | 眨眼 + 嘴角上扬 | 成功、入库 | 「洗完码好了，就在 /downloads/xx」 |
| failed | 眼罩歪斜 + 平嘴 | 失败、不支持 | 「这单没成：对方不放（403）。已开重试」 |
| cancelled | 平静 + 省略号嘴 | 主动取消 | 「行，不搬了。任务已撤」 |
| surprise | 两眼放光 + 大牙笑 | 彩蛋、追更到货 | 「追更到了！本集比预期大 3 倍」 |

文案人格：讲事实 + 给下一步；小机灵鬼式幽默；每界面至多一处拟人；禁嘲讽用户、禁装傻卖萌、禁空态文字羞辱。
六表情与品牌徽标共用 `--logo-*` 换皮变量：毛色/围巾随主题走（night=薄荷围巾、scarf=金围巾、snow=银灰、berry=珊瑚），
表情的骨架与五官在不同主题下保持同一只浣熊。

## 6. 动效与响应式

| 类型 | 参数 | 用途 |
| --- | --- | --- |
| 微反馈 | 120ms ease-out | hover/press/开关 |
| 面板抽屉 | 180–240ms cubic-bezier(.2,.8,.2,1) | 详情侧栏/对话框/通知中心 |
| 进度数字 | 240ms linear | 进度条/速度刷新 |
| 列表变更 | 180ms | 新任务插入高亮定位 |
| 禁用 | >400ms 入场、循环装饰动画、大渐变、玻璃拟态 | 尊重 prefers-reduced-motion（仅保留透明度变化） |

断点：≥1280 侧导航常驻+双栏；1024–1279 侧导航收图标栏；768–1023 抽屉+表格降级卡片；<768 单栏+底部主操作，触控目标 ≥44px，375px 关键按钮不遮挡。

底部栏（<768）：**5 高频 + 「更多」**（docs/15 §1.2 裁决 6）——主页 / 任务 / 历史 / 文件 / 设置，
其余 5 项（订阅 / 直播 / 日志 / 监控 / 连接）收进「更多」面板（3 列网格，每项 ≥56px 高）。
10 项在 375px 下每项只有 37px，横向滚动的方案被否（隐藏可及性问题）。

## 7. 交互状态与数据流（铁律）

- 状态唯一来源：SSE 事件 + `/tasks` 对账；前端 store 禁自行推算任务状态。
- 脏状态拦截：设置页表单脏 → 路由离开拦截（仅表单脏时）；保存结果按接口返回的 `effective_summary` 展示。
- 空态/加载/错误三分：骨架屏（加载）、引导空态（无数据）、错误卡+重试（失败）——不展示空白页。
- 快捷键（§9.10）：`/` 聚焦提交框、Esc 关闭/清除选择、↑↓ 移动、Enter 详情、Shift+Space 多选、R 重试、`G D`/`G S` 跳转；输入框内不触发（Esc 除外）。

## 8. 工程约定

- 组件 props/emits 全 TS 类型；API 层 types.ts 与后端 JSON 同字段名（隔离层只做 camelCase 展示转换）。
- 每视图配 `*.spec.ts`（vitest）：渲染 + 关键交互；组件走 @vue/test-utils。
- 构建产物 `web/dist` 由 Go `embed.FS` 内嵌（ADR-5）；CI：`npm ci && vue-tsc && vite build && vitest run`。
- 禁在模板写死色值/字号；发现硬编码即回 tokens.css 补变量。

### 8.1 合规闸门怎么立（血泪，务必遵守）

`scripts/check-design-conformance.py` 是本方案的**唯一验收闸门**。立错闸门比没有闸门更危险——
它会让人误以为已经达标。以下两条是实测踩出来的硬规矩：

**① 闸门必须查「验收点」，不能只查「存在性」。**

存在性断言（文件在不在、字符串有没有、被 import 过没有）只能证明「零件都在货架上」，
证明不了「组装出来像个产品」。真实翻车案例：旧闸门 100 项全 PASS，
但设置页导航只有 150px 宽、13.5px 字号、无当前项高亮、卡片网格用 `auto-fill` 导致 2 个卡片时右侧空 570px、
整页没有层级——**页骨架层压根没有闸门覆盖**，塌了没人拦。

闸门断言必须落在方案的可观测结果上，例如：

| 验收点 | 断言方式（不是"文件存在"） |
| --- | --- |
| 字号语义 | `--font-caption`(12px) 不得用于正文/标题（白名单只放表头/徽章/时间戳） |
| 卡片网格 | 禁 `repeat(auto-fill`；卡片类网格 `minmax` 列宽下限 240px |
| 行内操作区 | `.trow-ops` 必须显式 `flex-direction: row` |
| 视图级组件 | §3 点名的组件（QuickSubmit/StatusStrip…）必须被视图**真实引用**，不只是文件存在 |
| 导航高亮 | scrollspy 三个机制齐全：判定线 / 底部兜底 / 锚点点击锁定 |

**② 断言要查代码，不能查注释。**

注释里写「为什么不用 IntersectionObserver」是正常的推理记录，
用 `"IntersectionObserver" not in file` 断言会误报。断言前先剥掉注释行。

**③ 类型检查的退出码不能被管道吞掉。**

`npx vue-tsc --noEmit | tail -20; echo $?` 拿到的是 `tail` 的退出码，**永远是 0**，
类型错误会被完全掩盖，Docker 构建失败也看不出来（`docker compose build | tail` 同理）。
正确写法：

```bash
npx vue-tsc --noEmit > /tmp/tsc.log 2>&1; echo "exit=$?"; cat /tmp/tsc.log
docker compose build --progress plain > /tmp/build.log 2>&1; echo "exit=$?"
```

**④ 长页面的 scrollspy 三个边界必须显式兜住。**

设置页 6000px+、14 个分组，用 IntersectionObserver 会在"视口内无分组相交"时高亮突然消失。
改用判定线 scrollspy（判定线上方最后一个分组，rAF 节流）后，仍有两个坑：

- **页面底部**：最后一个分组永远越不过判定线 → 需 `scrollY + innerHeight >= scrollHeight` 时兜底高亮最后一个。
- **锚点被底部截断**：点「API 令牌」时目标 docTop=5564，但页面最大只能滚到 5329，
  目标被顶到视口 235px 处，判定线（140px）选不中 → 需点击时锁定到被点项，
  被点项滚出视口或用户主动滚动（wheel/touch/方向键）时自动解锁。

另有一个**首帧坑**：内容还没撑开时 `documentElement.scrollHeight` 是 0，
`innerHeight + scrollY >= scrollHeight - 2` 恒成立 → 会误高亮到最后一个分组。
必须加 `docH > innerHeight + 2` 前置条件。

这三条都要有对应单元用例，不能只靠人工看。

**⑤ CSS 层叠顺序：默认隐藏态必须写在媒体查询【之前】。**

CSS 同特异性下后写的赢。`.nav-toggle { display: none }` / `.tabbar { display: none }`
若写在媒体查询**之后**，会把媒体查询里的 `display: inline-flex` / `display: flex` 覆盖掉：

- 768–1023 档 → 汉堡按钮不显示，导航抽屉彻底打不开（用户在 900px 下完全没法导航）
- <768 档 → 底部主操作栏不渲染

实测踩过：四档截图里 `.nav-toggle` / `.tabbar` 全是 `display:none`，
而「规则存在」型断言全绿。**闸门要查层叠顺序，不能只查规则存在。**

**⑥ 移动端底部栏不能只有图标。**

移动端没有 hover tooltip，纯图标用户认不出哪个入口是哪个。
导航扩到 10 项后底部栏放不下（375px 每项只有 37px），改为 **5 高频 + 「更多」面板**：
5 项各占 1/6 宽度（每项 ≈54px，两字标签 12px 放得下），第 6 个槽位是「更多」。
「更多」面板里每一项仍是图标 + 完整文字（≥56px 高），不是纯图标网格。

### 8.2 字号语义映射（字阶不是随手挑）

| 用途 | Token | 字号 |
| --- | --- | --- |
| 页面大标题（PageHeader，句点收尾） | `--font-display` | 30px / 800 |
| 区块标题 | `--font-title-1` | 24px / 750 |
| 卡片标题（各视图 .card h2 / group-title 等） | `--font-title-2` | 20px / 700 |
| 次级标题（卡内小节，如失败拆分标题） | `--font-title-3` | 18px / 700 |
| 任务标题 / 说明句 / 页头副行 | `--font-body` | 16px / 400 |
| 元信息 / 提示 / 错误文案 | `--font-aux` | 14.5px |
