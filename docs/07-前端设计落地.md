## 2. 设计 Token（tokens.css，唯一色值来源）

浅色（默认）/ 深色两套；正文对比 ≥ WCAG AA 4.5:1；强调色只给主要动作（全屏金色 ≤3 处）。

```css
:root{
  /* 结构色：树影蓝灰 */
  --accent:#2B3644; --accent-strong:#1B2430;
  --accent-soft:#E6EAF0; --accent-softer:#F2F4F7;
  /* 动作色：围巾金 */
  --gold:#F5B93C; --gold-strong:#B8871A; --gold-soft:#FDF3DC;
  /* 画布 */
  --bg:#F6F6F2; --surface:#FFFFFF; --surface-2:#EEEF2; --surface-3:#E4E6EC;
  --border:#E2E5EF;
  /* 文字 */
  --text-1:#1B2133; --text-2:#4D5670; --text-3:#7E879F;
  /* 语义（饱和度较原蓝紫降 10%，不与金打架） */
  --success:#0F8A55; --warning:#A9740A; --danger:#CF4257; --info:#2F7DE1; --neutral:#667089;
  /* 圆角（v2.4「胖半号」） */
  --radius-ctrl:8px; --radius-card:14px; --radius-modal:20px; --radius-pill:999px;
  /* 阴影：树影色投影，禁纯黑 */
  --shadow-1:0 1px 2px rgba(43,54,68,.06);
  --shadow-2:0 8px 24px rgba(43,54,68,.10);
  --shadow-3:0 16px 48px rgba(43,54,68,.16);
  /* 字阶（docs/§10.3） */
  --font-display:30px/1.25 800; --font-title-1:24px 750; --font-title-2:20px 700;
  --font-title-3:18px 700; --font-body:16px/1.75 400; --font-aux:13.5px;
  --font-caption:12px 500;      /* 最小字号 12px，仅表头/徽章 */
}
[data-theme=dark]{
  --bg:#0F121B; --surface:#161A26; --surface-2:#1D2231; --surface-3:#232A3C;
  --border:#28304A; --text-1:#E9ECF5; --text-2:#AEB6CD; --text-3:#7E8AA5;
  --accent:#F5B93C; --accent-strong:#F8CD77; --accent-soft:#2E3746; --accent-softer:#28303F;
  --gold:#E8EDF3; --gold-strong:#FFFFFF; --gold-soft:#28303F;  /* 深底金 = 浣熊白高光 */
  --success:#4CC38A; --warning:#E0A84A; --danger:#F2728A; --info:#6FA8F0; --neutral:#8B94AD;
  --shadow-1:none; --shadow-2:0 0 0 1px var(--border); --shadow-3:0 0 0 1px var(--border);
}
```

规则：

- 数字一律 `font-variant-numeric:tabular-nums`（进度/速度/大小/时间）。
- 深色模式封面/缩略图加 1px 边框防「浮空」；深浅切换即时生效并记忆（immediate 设置）。
- 中英文混排预留间隙；术语/路径/命令保持原文不翻译。

## 5. 浣熊表情体系（§10.10 ③）

| 状态 | 表情 | 场景 | 文案示例 |
| --- | --- | --- | --- |
| waiting | 眼罩半搭 + 哈欠嘴 | 排队、等待登录 | 「排着呢，前面 3 个，急也没用」 |
| working | 眼罩推上头顶 + 叼金牌箭头 | 下载中、解析中 | 「搬着呢，43% · 12.4 MB/s」 |
| done | 眨眼 + 嘴角上扬 | 成功、入库 | 「洗完码好了，就在 /downloads/xx」 |
| failed | 眼罩歪斜 + 平嘴 | 失败、不支持 | 「这单没成：对方不放（403）。已开重试」 |
| cancelled | 平静 + 省略号嘴 | 主动取消 | 「行，不搬了。任务已撤」 |
| surprise | 两眼放光 + 大牙笑 | 彩蛋、追更到货 | 「追更到了！本集比预期大 3 倍」 |

文案人格：讲事实 + 给下一步；小机灵鬼式幽默；每界面至多一处拟人；禁嘲讽用户、禁装傻卖萌、禁空态文字羞辱。

## 6. 动效与响应式

| 类型 | 参数 | 用途 |
| --- | --- | --- |
| 微反馈 | 120ms ease-out | hover/press/开关 |
| 面板抽屉 | 180–240ms cubic-bezier(.2,.8,.2,1) | 详情侧栏/对话框/通知中心 |
| 进度数字 | 240ms linear | 进度条/速度刷新 |
| 列表变更 | 180ms | 新任务插入高亮定位 |
| 禁用 | >400ms 入场、循环装饰动画、大渐变、玻璃拟态 | 尊重 prefers-reduced-motion（仅保留透明度变化） |

断点：≥1280 侧导航常驻+双栏；1024–1279 侧导航收图标栏；768–1023 抽屉+表格降级卡片；<768 单栏+底部主操作，触控目标 ≥44px，375px 关键按钮不遮挡。

## 7. 交互状态与数据流（铁律）

- 状态唯一来源：SSE 事件 + `/tasks` 对账；前端 store 禁自行推算任务状态。
- 脏状态拦截：设置页表单脏 → 路由离开拦截（仅表单脏时）；保存结果按接口返回的 `effective_summary` 展示。
- 空态/加载/错误三分：骨架屏（加载）、引导空态（无数据）、错误卡+重试（失败）——不展示空白页。
- 快捷键（§9.10）：`/` 聚焦提交框、Esc 关闭/清除选择、↑↓ 移动、Enter 详情、Shift+Space 多选、R 重试、`G D`/`G S` 跳转；输入框内不触发（Esc 除外）。

## 8. 工程约定

- 组件 props/emits 全 TS 类型；API 层 types.ts 与后端 JSON 同字段名（隔离层只做 camelCase 展示转换）。
- 每视图配 `*.spec.ts`（vitest）：渲染 + 关键交互；组件走 @vue/test-utils。
- 构建产物 `web/dist` 由 Go `embed.FS` 内嵌（ADR-5）；CI：`npm ci && vue-tsc && vite build && vitest run`。
- 禁在模板写死色值/字号；发现硬编码即回 tokens.css 补变量。
