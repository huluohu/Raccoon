# 03 · 数据模型设计（SQLite）

> 唯一数据库文件 `data/raccoon.db`（WAL 模式）。全部 DDL 即 `internal/store/migrations/*.sql` 的源，本文档与迁移文件同源维护。
> 命名：表名单数、snake_case；时间一律 INTEGER Unix 毫秒（UTC）；布尔 INTEGER 0/1；金额/字节 INTEGER。

---

## 1. 设计约定

| 约定 | 说明 |
| --- | --- |
| 主键 | `id TEXT`（UUIDv4 去横线 32 位）或自增 INTEGER——对外暴露用 TEXT，事件/历史类大表用自增 |
| 时间 | Unix 毫秒 INTEGER；展示层转本地时区 |
| JSON | 扩展字段 `*_json` 存 TEXT，schema 演进不改表 |
| 软删 | 任务记录类不物理删除，`deleted_at` 置位；媒体文件删除是文件系统操作 + 索引更新 |
| 约束 | 状态字段 CHECK 约束（七态任务机，见 §4） |
| 并发 | 单写连接（`_txlock=immediate` + busy_timeout 5000），读多连接 |

## 2. 迁移策略

```
internal/store/migrations/
├── 0001_init.up.sql      # 建表（本文档 §3-§5 的合并产物）
└── 0002_<name>.up.sql    # 后续每个变更一个文件（禁改已发布迁移）
```

- 启动时 runner 读取 `schema_migrations`，按版本号事务内应用未执行迁移，记录 `version/applied_at/checksum`。
- 回滚：不提供自动 down 迁移；升级前备份数据库文件（部署文档步骤），迁移只能前进。
- 校验：迁移文件 checksum 入库，运行期发现已应用迁移被改动 → 拒绝启动并提示（防半迁移）。

## 3. 核心表 DDL

### 3.1 schema_migrations

```sql
CREATE TABLE IF NOT EXISTS schema_migrations (
  version    INTEGER PRIMARY KEY,
  name       TEXT    NOT NULL,
  checksum   TEXT    NOT NULL,
  applied_at INTEGER NOT NULL
);
```

### 3.2 users（账号，首发单管理员）

```sql
CREATE TABLE IF NOT EXISTS users (
  id            TEXT PRIMARY KEY,
  username      TEXT    NOT NULL UNIQUE,
  password_hash TEXT    NOT NULL,          -- Argon2id
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL,
  last_login_at INTEGER
);
```

### 3.3 api_tokens（API 凭据，可撤销/范围/有效期）

```sql
CREATE TABLE IF NOT EXISTS api_tokens (
  id           TEXT PRIMARY KEY,
  user_id      TEXT    NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name         TEXT    NOT NULL,
  token_hash   TEXT    NOT NULL UNIQUE,    -- SHA-256(token)，明文只返回一次
  scope        INTEGER NOT NULL DEFAULT 1, -- 位掩码：1=读 2=任务写 4=配置 8=删除文件
  expires_at   INTEGER,                    -- NULL=永久
  revoked_at   INTEGER,
  created_at   INTEGER NOT NULL,
  last_used_at INTEGER
);
CREATE INDEX IF NOT EXISTS idx_api_tokens_hash ON api_tokens(token_hash);
```

### 3.3a auth_sessions（Web 会话持久化，migration 0005）

```sql
CREATE TABLE IF NOT EXISTS auth_sessions (
  sid        TEXT PRIMARY KEY,           -- HttpOnly Cookie raccoon_session 的值
  user_id    TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  csrf_token TEXT NOT NULL,              -- 登录时下发，前端存内存随写请求带 X-CSRF-Token
  remember   INTEGER NOT NULL DEFAULT 0, -- 1=「30 天免登录」30 天滑动窗口；0=24h 滑动窗口
  created_at INTEGER NOT NULL,
  last_seen  INTEGER NOT NULL            -- 滑动续期基准（60s 节流落库）
);
CREATE INDEX IF NOT EXISTS idx_auth_sessions_user ON auth_sessions(user_id);
CREATE INDEX IF NOT EXISTS idx_auth_sessions_last_seen ON auth_sessions(last_seen);
```

应用重启后同一把 sid 照常校验，登录态跨重启保持；GC 每小时按 remember 双 TTL 清理。

### 3.4 credentials（凭据中心：Cookies/账号/Token）

```sql
CREATE TABLE IF NOT EXISTS credentials (
  id           TEXT PRIMARY KEY,
  platform     TEXT    NOT NULL,           -- youtube/bilibili/x/...
  kind         TEXT    NOT NULL CHECK (kind IN ('cookie_file','account','token','session')),
  label        TEXT    NOT NULL,
  ciphertext   BLOB    NOT NULL,           -- AES-256-GCM(ciphertext+nonce)
  status       TEXT    NOT NULL DEFAULT 'active'
               CHECK (status IN ('active','expiring','expired','disabled')),
  note         TEXT,                       -- 健康说明（失败原因摘要）
  expires_at   INTEGER,
  last_check_at INTEGER,
  created_at   INTEGER NOT NULL,
  updated_at   INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_credentials_platform ON credentials(platform, kind);
```

### 3.5 settings / setting_history（配置中心）

```sql
CREATE TABLE IF NOT EXISTS settings (
  key            TEXT PRIMARY KEY,
  value_json     TEXT    NOT NULL,
  effective      TEXT    NOT NULL DEFAULT 'next_task'
                  CHECK (effective IN ('immediate','next_task','restart')),
  sensitive      INTEGER NOT NULL DEFAULT 0,
  locked_by_env  TEXT,                     -- 非空=被该环境变量锁定，界面只读
  version        INTEGER NOT NULL DEFAULT 1,
  updated_at     INTEGER NOT NULL,
  updated_by     TEXT
);
CREATE TABLE IF NOT EXISTS setting_history (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  key        TEXT    NOT NULL,
  value_json TEXT    NOT NULL,
  version    INTEGER NOT NULL,
  changed_at INTEGER NOT NULL,
  changed_by TEXT,
  note       TEXT
);
CREATE INDEX IF NOT EXISTS idx_setting_history_key ON setting_history(key, id DESC);
```

## 4. 任务系统表（七态状态机的落点）

### 4.1 tasks

```sql
CREATE TABLE IF NOT EXISTS tasks (
  id             TEXT PRIMARY KEY,
  parent_id      TEXT REFERENCES tasks(id) ON DELETE CASCADE,  -- 父/子任务
  kind           TEXT    NOT NULL DEFAULT 'download'
                 CHECK (kind IN ('download','record','qb','n115','postprocess')),
  source         TEXT    NOT NULL
                 CHECK (source IN ('web','telegram','api','cli','extension','subscription','live','system')),
  source_ref     TEXT,                       -- 如 telegram chat_id / subscription_id
  platform       TEXT,                       -- youtube/bilibili/qbittorrent/...
  url            TEXT    NOT NULL,
  title          TEXT,
  thumbnail      TEXT,
  dedupe_key     TEXT    NOT NULL,           -- 重复提交检测：sha1(kind|platform|规范化url)
  status         TEXT    NOT NULL DEFAULT 'waiting'
                 CHECK (status IN ('waiting','parsing','downloading','post','done','failed','cancelled')),
  wait_reason    TEXT,                       -- 需登录/等待授权/磁盘检查（不占失败态）
  quality        TEXT,                       -- 选定质量（配置快照）
  save_path      TEXT,                       -- 相对 data 根的路径
  convert_to     TEXT,                       -- 产物目标格式：NULL=源格式 / mp4 / mp3（0010 迁移新增；post 阶段 ffmpeg 处理）
  proxy          TEXT    NOT NULL DEFAULT '', -- 任务级网络代理（0011 迁移新增；空=跟随系统策略）
  expected_size  INTEGER,                    -- 未知=NULL，禁估算
  downloaded_size INTEGER NOT NULL DEFAULT 0,
  speed_bps      INTEGER NOT NULL DEFAULT 0,
  progress       REAL    NOT NULL DEFAULT 0, -- 0-100，解析阶段允许 0
  resume_supported INTEGER NOT NULL DEFAULT 0,
  engine         TEXT,                       -- ytdlp/ffmpeg/gallerydl/qbittorrent/n115
  engine_version TEXT,
  config_version INTEGER NOT NULL,           -- 创建时配置版本（快照）
  attempt        INTEGER NOT NULL DEFAULT 0,
  max_attempts   INTEGER NOT NULL DEFAULT 3,
  error_code     TEXT,
  error_message  TEXT,
  fix_hint       TEXT,                       -- 可执行修复提示（含跳转 action）
  route_path     TEXT    NOT NULL DEFAULT '', -- 存储策略「走了哪条路」的人类可读链路（migration 0006）
  cancel_requested INTEGER NOT NULL DEFAULT 0,
  scheduled_at   INTEGER,                    -- 订阅/直播的到期扫描
  deleted_at     INTEGER,
  created_at     INTEGER NOT NULL,
  updated_at     INTEGER NOT NULL,
  started_at     INTEGER,
  finished_at    INTEGER
);
CREATE INDEX IF NOT EXISTS idx_tasks_status   ON tasks(status, scheduled_at) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_tasks_parent   ON tasks(parent_id);
CREATE INDEX IF NOT EXISTS idx_tasks_dedupe   ON tasks(dedupe_key) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX IF NOT EXISTS idx_tasks_active_dedupe
  ON tasks(dedupe_key) WHERE status IN ('waiting','parsing','downloading','post');
CREATE INDEX IF NOT EXISTS idx_tasks_source   ON tasks(source, source_ref);
CREATE INDEX IF NOT EXISTS idx_tasks_created   ON tasks(created_at DESC) WHERE deleted_at IS NULL;
```

> `idx_tasks_active_dedupe`：同一 dedupe_key 只允许一个活跃任务——重复提交在 DB 层兜底（应用层先查再报友好提示）。

### 4.2 task_events（流水与日志，详情页「日志」区数据源）

```sql
CREATE TABLE IF NOT EXISTS task_events (
  id       INTEGER PRIMARY KEY AUTOINCREMENT,

  ts       INTEGER NOT NULL,
  level    TEXT    NOT NULL DEFAULT 'info' CHECK (level IN ('debug','info','warn','error')),
  event    TEXT    NOT NULL,                -- status_change/progress/engine_line/retry/...
  message  TEXT,
  fields_json TEXT
);
CREATE INDEX IF NOT EXISTS idx_task_events_task ON task_events(task_id, id);
```

### 4.3 task_files（任务产物）

```sql
CREATE TABLE IF NOT EXISTS task_files (
  id       TEXT PRIMARY KEY,
```

## 5. 业务表

### 5.1 subscriptions / subscription_items

```sql
CREATE TABLE IF NOT EXISTS subscriptions (
  id             TEXT PRIMARY KEY,
  platform       TEXT    NOT NULL,
  source_type    TEXT    NOT NULL CHECK (source_type IN ('favorite','uploader','list')),
  source_id      TEXT    NOT NULL,
  source_url     TEXT    NOT NULL,
  title          TEXT,
  mode           TEXT    NOT NULL DEFAULT 'new_only'
                 CHECK (mode IN ('new_only','backfill','range')),
  range_from     INTEGER,
  range_to       INTEGER,
  quality        TEXT,
  save_rule      TEXT,                      -- 命名规则快照引用（见设置 save_rules）
  interval_min   INTEGER NOT NULL DEFAULT 30,
  enabled        INTEGER NOT NULL DEFAULT 1,
  credential_id  TEXT REFERENCES credentials(id) ON DELETE SET NULL,
  last_checked_at INTEGER,
  last_item_id   TEXT,
  next_check_at  INTEGER NOT NULL,
  error_note     TEXT,
  created_at     INTEGER NOT NULL,
  updated_at     INTEGER NOT NULL,
  UNIQUE (platform, source_type, source_id)
);
CREATE TABLE IF NOT EXISTS subscription_items (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  subscription_id TEXT   NOT NULL REFERENCES subscriptions(id) ON DELETE CASCADE,
  item_id        TEXT    NOT NULL,          -- 平台内容 ID（如 BV 号）
  title          TEXT,
  task_id        TEXT REFERENCES tasks(id) ON DELETE SET NULL,
  status         TEXT    NOT NULL DEFAULT 'pending'
                 CHECK (status IN ('pending','queued','downloaded','skipped','failed')),
  discovered_at  INTEGER NOT NULL,
  UNIQUE (subscription_id, item_id)          -- 防重复下载的 DB 兜底
);
CREATE INDEX IF NOT EXISTS idx_sub_items_status ON subscription_items(subscription_id, status);
```

### 5.6 monitor_sample（监控历史聚合，migration 0006）

```sql
CREATE TABLE IF NOT EXISTS monitor_sample (
  ts     INTEGER PRIMARY KEY,   -- Unix 秒，1 分钟聚合桶的起点
  cpu    REAL NOT NULL,
  memory REAL NOT NULL,
  disk   REAL NOT NULL,
  net_rx REAL NOT NULL,
  net_tx REAL NOT NULL
);
```

口径（docs/15 §4.1）：sampler 每 2s 采一次、内存环形缓冲 60 点（实时序列），
每 1 分钟把这一分钟的均值落一行；**保留 7 天**，由聚合写入口顺手删除过期行。
1440 行/天 × 7 ≈ 1 万行，量级可忽略。`GET /system/monitor/history?range=1h|24h`
直接按 `ts` 区间查，`granularity_sec` 分别为 60 / 1440。

### 5.7 user_preferences（界面偏好，migration 0007）

```sql
CREATE TABLE IF NOT EXISTS user_preferences (
  user_id    TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  key        TEXT NOT NULL,
  value      TEXT NOT NULL DEFAULT '',
  updated_at INTEGER NOT NULL,
  PRIMARY KEY (user_id, key)
);
```

用途：E1 主页布局（`key='dashboard_layout'`，`value` 是 JSON **字符串**：
`{"hidden":[...],"order":[...]}`）。为什么不借用配置中心（docs/15 §3.6）：
配置中心是「全局生效 + 有版本快照 + 影响任务」的语义，布局偏好是「按人 + 不影响任务」，
混进去会让 config_version 因为一个人的界面勾选而变动。

## 6. 数据量与容量说明

| 表 | 预估量级（家庭场景 2 年） | 措施 |
| --- | --- | --- |
| tasks | 10 万级 | 按 created_at 分页；详情日志按 task_id 查 |
| task_events | 百万级 | 引擎逐行日志默认只存 warn/error + 结构化事件；debug 存文件不进库 |
| media_files | 万级 | 路径唯一索引 + 平台索引 |
| notifications | 万级 | 已读 30 天清理任务 |
| monitor_sample | 约 1 万行（7 天滚动） | 聚合写入口删过期行，不做归档 |

SQLite 单文件在上述量级无压力；出现多用户并发写入需求再评估迁移（方案 §4.2 边界）。

## 7. 关键查询模式（实现约束）

| 模式 | 写法 | 禁 |
| --- | --- | --- |
| 分页 | `WHERE ... ORDER BY created_at DESC LIMIT ? OFFSET ?`（游标 `created_at,id` 用于深页） | 无界拉取 |
| 状态变更 | 单条 UPDATE + 同事务写 task_events | 先 SELECT 再 UPDATE 的读改写（用乐观版本号或串行写） |
| 统计 | `SELECT status, COUNT(*) FROM tasks WHERE deleted_at IS NULL GROUP BY status` | 把统计塞进列表接口逐行算 |
| JSON 检索 | 仅展示用，查询依赖真实列 | 用 LIKE 查 JSON 字段做业务过滤 |
