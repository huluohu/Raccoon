### 2.4 恢复语义（kill -9 实测）

1. 任务处于 `downloading` 时 `kill -9` 服务进程；
2. 重启后日志出现 `恢复扫描完成 {"status":"downloading","count":1}`；
3. 任务回到 `waiting` + `wait_reason=interrupted`，事件如实记录：
   `进程重启，任务被中断；无法保证从原字节位置续传，将重新排队`；
4. 25s 后被调度器重新领取，回到 `downloading`。

## 3. 过程中发现并修复的真实缺陷

以下均为实测暴露、非推测。

### 3.1 SQLite NULL → string 扫描失败（列表与详情 500）

`error_code / error_message / fix_hint` 允许为 NULL，而 `scanTask` / `scanTaskRows` 直扫 `string`，
任务一旦有数据就报 `converting NULL to string is unsupported`，表现为列表 500、调度静默。

**修复**：三字段经 `sql.NullString` 中转。

### 3.2 默认质量 `best` 在纯 DASH 站点必然失败

内部默认 `quality=best` 落入 `formatSelector` 的 `default` 分支，被原样透传为 `-f best`；
B 站只有 video-only / audio-only 分离流，无 combined 流，yt-dlp 直接
`FORMAT_UNAVAILABLE`。**修复**：`best` 映射为 `bv*+ba/b`（与 1080p 等档一致）。

### 3.3 下载产物落错目录（服务 cwd）

`RunCmd` 未设置子进程工作目录，yt-dlp 的 `-o` 相对模板导致文件落到**服务进程 cwd**
（实测 21MB 视频出现在工作区目录而非 `downloads/bilibili/`）。
**修复**：`RunCmd` 增加 `dir` 参数传 `SaveDir`；同时 `[download] Destination:` 输出的是相对路径，
`collectFiles` 增加拼回 `SaveDir` 的逻辑。

### 3.4 自动重试任务永久卡死

`DueWaiting` 的过滤条件含 `wait_reason IS NULL OR wait_reason=''`，
而退避任务写入 `wait_reason=auto_retry`，导致退避到期后**永远不被领取**。
**修复**：调度只按 `scheduled_at` 判到期，`wait_reason` 退回纯展示字段（docs/05 §3 口径）。

### 3.5 布尔列扫描（首次列表 500 / scheduler 静默）

`cancel_requested / resume_supported` 为 INTEGER，不能直扫 `bool`，
已用 `int64` 中转（与 3.1 同批修复）。

### 3.6 SSE 心跳/连接与测试方式

SSE 实现正常（心跳 + 事件）。验证初期只收到 1 条事件，是测试脚本用
`(curl … &)` 后台订阅时被 SIGHUP 杀掉，非产品缺陷；改用受管后台任务后事件流完整。

### 3.7 软删除任务仍占用 dedupe key（409）

删除任务后重新提交同一链接仍返回 409：`activeByDedupe` 查询与
`idx_tasks_active_dedupe` 唯一索引都没有排除 `deleted_at IS NULL`。
**修复**：查询加 `deleted_at IS NULL`；新增迁移 `0002_dedupe_exclude_deleted.up.sql`
重建唯一索引（不能改 0001 —— checksum 防篡改会拒绝）。

## 4. 已知限制（如实记录，不掩盖）

| 限制 | 现状 | 后续 |
| --- | --- | --- |
| kill -9 后 yt-dlp 变孤儿进程 | 实测父进程被 SIGKILL 后子进程仍在跑并继续落盘；Docker 部署应加 `--init`（tini 回收子进程） | Wave 4 部署加固 |
| 同名产物撞名 | 不同清晰度下载同一视频时产物文件名相同，yt-dlp 判定已存在直接跳过 → `NO_OUTPUT` | 保存策略需带清晰度维度，或按 `save_path` 分目录 |
| `/system/restart` 让出重启端点 | 未实现（当前靠 SIGTERM 优雅停机，`ShutdownTasks` 已实测生效） | 2.6 剩余项 |
| 大文件下载偏慢 | 平台侧限速（实测 ~140KB/s），非本地瓶颈 | 换源/多线程策略留 Wave 4 |
| 前端仅「下载」页落地 | 总览/媒体库/订阅/直播/连接/设置仍是骨架占位 | Wave 3 |
